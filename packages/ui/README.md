# `@sichentao/ui`

Framework-independent component foundations. The package exposes:

- CSS classes for buttons, icon buttons, fields, cards, badges, alerts, skeletons, links, and state panels.
- TypeScript attribute contracts that can be spread by Astro, React, Vue, or a string-template renderer.
- Small DOM bindings for disclosures, pressed controls, live-region announcements, and async state changes.
- Typed references to the existing icon sprite, portrait, institution marks, and workspace marks.

Import the design-token CSS first, then `@sichentao/ui/css`. Component copy remains the product application's responsibility so English, Chinese, and Japanese stay synchronized.
