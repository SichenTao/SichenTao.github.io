EvoSort: 大規模高性能計算のための遺伝的アルゴリズムベース適応型並列ソートフレームワーク

著者：S. NagaMallik Raj, Kalyanmoy Deb

International Journal of Parallel Emergent and Distributed Systems2025年12月31日DOI https://doi.org/10.1080/17445760.2025.2609138
IF 0.6JCR N/ACAS Q4被引用 0
#大規模最適化#ソーティングとデータ処理#AI#進化計算

要旨本文

本研究では、Python レベルで利用可能な汎用の適応型並列ソートフレームワーク EvoSort を提案する。EvoSort は遺伝的アルゴリズム（GA）を用いて、挿入ソートのしきい値やアルゴリズム選択（マージソートと LSD 基数ソート）などの重要なパラメータを自動的に発見し改良する。入力データとシステムアーキテクチャに継続的に適応することで、EvoSort は NumPy や Pandas などの標準的な Python ルーチンに対するドロップイン置換として機能する。9 種類のデータ分布と 2 種類のハードウェアプラットフォームで、最大 10^10（100 億）要素を対象に行った実験により、EvoSort は競合手法を一貫して上回ることが示された。結果として最大 225 倍の高速化が得られ、大規模データ処理に対する強力な自動チューニング手法であることが示された。
