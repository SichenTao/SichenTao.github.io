EvoX：面向可扩展进化计算的分布式 GPU 加速框架

作者：Beichen Huang, Ran Cheng, Zhuozhao Li, Yaochu Jin, Kay Chen Tan

IEEE Transactions on Evolutionary Computation2024年4月15日DOI https://doi.org/10.1109/tevc.2024.3388550
IF 11.7JCR Q1CAS Q1 Top被引 26
#优化问题#多目标优化#AI#进化计算

摘要正文

受自然进化过程启发，进化计算（EC）已成为人工智能的基石之一。近年来，随着数据密集型应用和大规模复杂系统的激增，对可扩展 EC 解决方案的需求显著增长。然而，现有大多数 EC 基础设施无法满足大规模问题求解不断提升的需求。尽管一些开创性的 GPU 加速 EC 库的出现是重要进展，但它们也面临若干局限，特别是在灵活性和架构鲁棒性方面。为此，本文提出 EvoX：一个面向 EC 算法自动化、分布式和异构执行的计算框架。EvoX 的核心是一个独特的编程模型，用于简化可并行化 EC 算法的开发，并辅以一个专门针对分布式 GPU 加速优化的计算模型。在此基础上，本文构建了一个包含 50 多种 EC 算法的广泛库，覆盖单目标和多目标优化。此外，该库为多样化基准问题提供全面支持，范围从数十个数值测试函数到数百个强化学习任务。通过在一系列问题场景和硬件配置上的大量实验，EvoX 展示出稳健的系统性能和模型性能。EvoX 是开源的，可见：https://github.com/EMI-Group/EvoX。
