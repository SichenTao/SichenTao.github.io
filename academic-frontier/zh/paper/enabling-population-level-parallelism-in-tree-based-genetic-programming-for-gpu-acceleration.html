面向 GPU 加速的树式遗传程序中的种群级并行性实现

作者：Zhihong Wu, Lishuang Wang, Kebin Sun, Zhuozhao Li, Ran Cheng

IEEE Transactions on Evolutionary Computation2026年1月1日DOI https://doi.org/10.1109/tevc.2026.3663396

摘要正文

树式遗传编程（TGP）是一种广泛用于符号回归、分类和机器人控制等任务的进化算法。由于运行 TGP 的计算需求很高，GPU 加速对于实现可扩展性能至关重要。然而，高效的基于 GPU 的 TGP 执行仍然具有挑战，主要源于三个核心问题：（1）程序个体的结构异质性；（2）整合多层次并行性的复杂性；（3）高性能 CUDA 执行与灵活 Python 环境之间的不兼容。为解决这些问题，本文提出 EvoGP，这是一个面向 TGP GPU 加速的高性能框架，通过种群级并行执行实现加速。首先，EvoGP 引入一种张量化表示，将可变大小的树编码为固定形状、内存对齐的数组，从而在多样个体之间实现统一内存访问和并行计算。其次，EvoGP 采用自适应并行策略，根据数据集规模动态结合个体内和个体间并行性，确保在广泛任务上实现较高 GPU 利用率。第三，EvoGP 将自定义 CUDA 内核嵌入 PyTorch 运行时，与 Gym、MuJoCo、Brax 和 Genesis 等基于 Python 的环境实现无缝集成。实验结果表明，EvoGP 的峰值吞吐量超过 10^11 GPops/s。具体而言，相比现有基于 GPU 的 TGP 实现，该性能最高提升 304 倍；相比最先进的 CPU 库，最高提升 18 倍。此外，EvoGP 保持了相当的精度，并在大种群规模下表现出更好的可扩展性。EvoGP 开源地址为：https://github.com/EMI-Group/evogp。
