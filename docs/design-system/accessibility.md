# 可访问性目标与测试合同

## 目标边界

v2 设计系统以 WCAG 2.2 AA 作为工程目标。当前代码建立必要契约，完整符合性仍需在每个真实页面、文案、数据状态和浏览器组合上测试，因此不能仅凭组件包宣称全站合规。

## 必须保持的行为

1. 所有交互可用键盘完成，焦点顺序与视觉顺序一致，Escape 能关闭临时 disclosure。
2. `:focus-visible` 清晰可见；页面不得用全局 `outline: none` 覆盖它。
3. 图标按钮有本地化可访问名称，装饰 SVG 从辅助技术树中隐藏。
4. loading、error、empty、stale、paywalled 具有可见文字和适当 live-region 语义。
5. `prefers-reduced-motion: reduce` 关闭平滑滚动并缩短动画；关键信息不依赖动画出现。

系统强制色模式下，表单、按钮、卡片、提示和状态面板使用系统 CanvasText 边框，键盘焦点使用系统 Highlight 色，避免主题色被替换后丢失边界。

## 页面级验收

- 仅键盘走完导航、搜索、筛选、语言、主题、登录、结账返回、订阅管理和受保护下载。
- 在 200% 缩放、320 CSS px 宽度和中文、英文、日文长文案下无水平信息丢失。
- 使用 VoiceOver 检查 landmark、标题层级、表单名称、结果计数和异步播报。
- 自动化运行 axe 或等价规则；人工复核颜色对比、焦点可见性、错误恢复和认知负担。
- 真实页面执行减弱动效、深链接、前进后退、网络失败和登录过期测试。

## 状态播报限制

相同状态不应在每次渲染时重复写入 live region。结果列表快速筛选时应合并播报，并在用户停止输入后更新结果数量。错误用 assertive；普通加载完成、空结果和过期提示使用 polite。

## 触控和尺寸

主要移动控制使用 production 已有的 44 px 高度。30 或 34 px 的紧凑控件只用于 header 内的次级操作，并保持足够间距和可见名称。整卡点击不能遮挡内部按钮的独立触控区域。
